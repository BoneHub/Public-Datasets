BoneHub Public Datasets

A Guide for finding 3D bone shapes & medical image datasets

📖 About

A curated collection of publicly available datasets with 3D bone shapes or medical images (CT, MRI) from which bone shapes can be extracted. Designed for researchers in biomedical engineering, medical imaging, biomechanics, and related fields.

📌 Note: This repository does not host datasets — only metadata and links are provided.
